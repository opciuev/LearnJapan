## 重要度标记

- ★ 跟老师重点学：新活用、易混助词、条件、语态、推测证据、敬语视角，或后续语法的重要前置。
- ● 常用掌握：使用频率较高，但结构建立在已学规则上，课堂理解后可自行巩固。
- ○ 简单自学：固定表达、透明规则或结构新意较少的内容。

这个等级表示学习优先级，不等同于 JLPT 等级或考试出现频率。

## 推荐使用方法

1. 先看总路线图，确定当前课属于哪条主干。
2. 上课前只预习本阶段图中的 ★ 项。
3. 上课时重点确认每张图底部的“重点对比”。
4. 课后完成 ★，再补 ●；○ 项可集中自学。
5. 复习时沿总图横向关系轨道串联，不需要逐课孤立背诵。

关系采用“同色关系轨道、阶段列、底部对比带”表达，只保留会影响后续理解的主干，因此没有让大量连线穿过正文。
