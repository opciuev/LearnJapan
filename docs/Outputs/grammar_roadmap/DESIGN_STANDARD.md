# 1～48课语法图设计与验收标准

## 目标

语法图不是教材截图，也不是把语法条目简单堆在一起。它需要让学习者在一张图中回答六个问题：

1. 本课学什么？
2. 句子怎么组成？
3. 什么时候使用？
4. 最容易错在哪里？
5. 它承接哪一课、为哪一课做准备？
6. 需要跟老师重点学，还是可以简单自学？

## 固定信息结构

每张单课图按以下顺序组织：

1. **课名与记忆钩子**：用普通中文概括本课能力，不发明“判断轨”等术语。
2. **学习位置**：显示所在阶段，并只标出直接相关的前一课或后一课。
3. **学习优先级图例**：
   - ★ 跟老师重点学：易错、会反复出现或会影响后续理解。
   - ● 需要熟练：常用且应能独立造句。
   - ○ 看懂即可：规则直观、练习一次通常就能掌握。
4. **语法卡片**：每张卡固定包含“句型、作用、例句、易错”。
5. **关系标签**：说明“承接第X课”“为第X课准备”或“易与第X课混淆”。
6. **课内规律**：用一条学习顺序和一条判断诀窍收束本课。

## 关系表达规则

- 每张语法卡最多保留 **1 个**跨课程关系标签。
- 一张单课图原则上不画跨卡片连线；可以用阅读顺序、位置和文字标签表达关系。
- 只保留会影响“现在怎么学”或“以后在哪里复用”的关系。
- 关系必须能在总 Roadmap 或 `_data/grammar.yml` 中核对。
- 禁止使用学习者看不懂的自创术语。

## 版式与视觉规则

- 单课图最多 6 张核心语法卡；超过 6 张时按知识家族拆分，不压缩正文。
- 所有卡片使用同一尺寸、圆角、字体、行距和中性边框。
- 优先级只通过 ★／●／○及标题颜色表达，不使用大面积警示色。
- 正文颜色固定：句型与说明为深灰、例句为蓝色、易错为红色、关系标签为浅蓝色。
- 阅读顺序为从上到下、从左到右；不要求读者沿线寻找正文。
- 在 2000 px 宽 PNG 中，正文必须无需放大即可阅读；不得出现裁切、重叠和文字贴边。

## 内容准确性规则

- `_data/grammar.yml` 是本课语法与例句的第一来源。
- 总 Roadmap 是跨课程关系和阶段名称的第一来源。
- 可以补充记忆钩子和易错说明，但不能改变原语法含义。
- 日语例句必须与句型一致；中文翻译应自然且能帮助判断使用场景。
- 每张卡只讲一个核心区别；需要比较时，把差异写进“易错”或底部“判断诀窍”。

## 10分验收清单

每项通过计 1 分；只有全部通过才视为模板可推广到其他课程。

- [ ] 1. 本课语法条目与来源一致，没有漏项或错误扩展。
- [ ] 2. 标题和卡片名称使用普通中文，一眼能知道在学什么。
- [ ] 3. 每张卡都有句型、作用、例句和易错点。
- [ ] 4. ★／●／○均有明确图例，且标记符合真实学习成本。
- [ ] 5. 每个跨课关系都能在 Roadmap 中核对。
- [ ] 6. 每卡最多一个关系标签，整图没有干扰正文的线条。
- [ ] 7. 学习位置、语法正文、课内总结三级层次清楚。
- [ ] 8. 与其他课程使用相同的颜色、字体、卡片和标签规则。
- [ ] 9. 导出的 2000 px PNG 无裁切、重叠、过密或难以阅读的文字。
- [ ] 10. 每课只保留一个 `.drawio` 源文件和一个最终 `.png`，评审临时图及时清理。

## 文件交付规则

- 单课源文件：`lesson_details/LXX.drawio`
- 单课最终图：`lesson_details/LXX.png`
- 最终 PNG 必须嵌入 draw.io 数据，便于后续继续编辑。
- 每次改版后依次执行：结构校验 → 2000 px 预览 → 视觉检查 → 最终嵌入导出 → 清理临时预览。
