# 1–48课逐课语法详解图

这里包含48张可独立学习的逐课图，共277张语法卡片。每张卡都给出接续、作用、日语例句、中文对应和易错点；图底部用“本课结构关系”串联同课语法，因此不需要依赖大量穿过正文的连线。

书本不再是理解这些图的前置条件。遇到语境、课文对话或练习题时，再回书中补充即可。

- ★：建议跟老师重点学，通常是活用底座、易混结构、语态、条件或敬语方向。
- ●：常用掌握，理解规则后可以配合练习巩固。
- ○：结构简单或以识别为主，适合自学。
